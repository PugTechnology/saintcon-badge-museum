# SAINTCON Badge Emulator & Multi-Year Museum

Browser-based hardware shell (`emulator/web/index.html`), multi-year badge museum (`emulator/web/museum.html`), and native headless script runners for SAINTCON electronic conference badges:

- **2018, LED matrix badge (our description, upstream gives no title)** (`?year=2018`): ESP32 (LOLIN D32) padlock PCB (`Saintcon2018.kicad_pcb`), arched 8×32 discrete red 0603 LED matrix (`D1..D256`) driven by two `IS31FL3730` I2C dual-8×8 matrix drivers (`U2` at `0x60`, `U3` at `0x61`), 3 tactile switches (`SW1`=`UP`, `SW2`=`DOWN`, `SW3`=`SELECT`), second I2C bus (`i2c2`, 10 kHz) for 5 minibadge addresses (`0x01, 0x29, 0x40, 0x41, 0x42`), and `microWebSrv` Wi-Fi AP config portal (`www/`), running `compukidmike` and `miketweaver`'s original SAINTCON 2018 MicroPython firmware (`mode=stock`, "Original Firmware") inside MicroPython `v1.24.1` compiled to WebAssembly (`ports/webassembly`).
- **2021, combination lock badge (our description, upstream gives no title)** (`?year=2021`): ATSAME53J18A combination lock PCB (`Saintcon2020Front.kicad_pcb` + `Saintcon2020Shackle.kicad_pcb` + `Saintcon2020.kicad_pcb`), circular `240×240` ILI9331 16-bit parallel LCD, 3-channel QTouch capacitive dial wheel + 4 shackle/shim capacitive sensors, tactile Back button (`SW3`), 1 RGB LED (`D1`), 512-byte `NVMCTRL` SmartEEPROM, 8 MB QSPI external flash (`flash.bin` generated by `ExternalFlash/makeFlash.py`), ST25R95 SPI NFC reader/tag emulator, and `I2C_0` minibadge bus, running `compukidmike`, `Professor_Plum`, and `Sodium_Hydrogen`'s original SAINTCON 2021 C firmware (with firmware contribution from `kfeuz`, `mode=stock`, "Original Firmware") paired with an on-page virtual NFC tag, registration vCard, solo `"Museum Bot"` trade, and I2C minibadge panel.
- **2023 — "Incidents"** (`?year=2023`): ESP32-S3 landscape dungeon-crawler badge (`Saintcon2023.kicad_pcb`), rectangular `320×240` ST7789 8-bit 8080 parallel LCD, 20 SK6812MINI LEDs (`D1..D20`), 4-way + center navigation switch (`SW5`) + `A` & `B` action buttons (`SW2`, `SW3`), NEC IR TX/RX, fixed MC3419 accelerometer, silent TFA9879 audio shim, and 4 virtual I2C minibadge slots (`U9, U10, U13, U14`), running `compukidmike`'s original SAINTCON 2023 firmware (`mode=stock`, "Original Firmware") backed by a per-visitor in-browser fake `sc23-api` game server (`badges/2023/fake-server.js`) and `"Incidents Companion"` panel.
- **2024 — "Tower Battle"** (`?year=2024`): ESP32-S3 landscape wrist badge (`Saintcon2024.kicad_pcb` + `Saintcon2024Top.kicad_pcb`), rectangular `320×240` ST7789 8080 parallel LCD with GT911 capacitive touchscreen, NEC IR TX/RX, MC3419 accelerometer, and TCA9544A Klip-on I2C mux, running `compukidmike`'s original SAINTCON 2024 firmware (`mode=stock`, "Original Firmware") backed by a per-visitor in-browser fake tower server (`badges/2024/fake-server.js`) and an 11-station virtual IR `"Towers"` panel.
- **2025 — "The Wrench"** (`?year=2025`): ESP32-S3 wrench PCB (`Saintcon2025.kicad_pcb`), rectangular `240×320` ST7789V LCD, 20 WS2812B-2020 LEDs (`D1..D20`), 5-way navigation switch (`SW2`), 512-byte ST25DV04K NFC EEPROM, with **two selectable modes**:
  - `mode=stock` (default): original SAINTCON 2025 conference firmware & 31-node faction game by `compukidmike` (`core-stock.js` / `core-stock.wasm`), backed by a per-visitor in-browser fake game server (`badges/2025/fake-server.js`) and solo virtual NFC "Nut" dispenser.
  - `mode=pug`: virtual pug pet & mini-games firmware (`core.js` / `core.wasm`).
- **2026 — "Orion Trail"** (`?year=2026`): RP2350A Apollo rocket PCB (`Apollo.kicad_pcb`), circular `360×360` ST77916 QSPI LCD, 9 WS2812C-2020 LEDs (`D4..D11, D3`), 5-way navigation switch (`SW4`, center=`C`) + two action buttons (`SW2`=`A`, `SW3`=`B`), 1024-byte 24CS08 I2C EEPROM, running Professor-plum's stock *Orion Trail* space-exploration game (`mode=stock`, offline standalone crew mode).

- **Year & Mode Resolution**: `emulator/web/index.html` resolves the badge year from `?year=<year>` (default `2025`) or from the host `<yy>.sc.pug.technology` (e.g. `21.sc.pug.technology` = 2021, `24.sc.pug.technology` = 2024, `25.sc.pug.technology` = 2025), fetches `badges/<year>/badge.json`, configures screen dimensions, shape (`rect` vs `round` circular mask), capacitive touch or button bitmask/keybindings, LED count, EEPROM size, modes, and credits, and loads `badges/<year>/core.js` + `core.wasm`.
- **Per-Year & Per-Mode Browser Storage**: `localStorage` keys are scoped by year and mode:
  - `saintcon_<year>_<mode>_eeprom` (e.g. `saintcon_2018_stock_eeprom`, `saintcon_2021_stock_eeprom`, `saintcon_2023_stock_eeprom`, `saintcon_2025_pug_eeprom`, `saintcon_2025_stock_eeprom`, `saintcon_2026_stock_eeprom`)
  - `saintcon_2018_stock_minibadges`, `saintcon_2018_stock_hc_score` (virtual I2C2 minibadge selections and stand-in Hacker Challenge score for 2018 stock mode; `wifi.json` flash config is persisted in `saintcon_2018_stock_eeprom`)
  - `saintcon_2021_stock_vcard`, `saintcon_2021_stock_minibadge` (512-byte QSPI flash vCard sector at `0x7F8000` and virtual `0x28` I2C minibadge state for 2021 stock mode; 512-byte `NVMCTRL` SmartEEPROM state is persisted in `saintcon_2021_stock_eeprom`)
  - `saintcon_2023_stock_server`, `saintcon_2023_stock_minibadges` (isolated `sc23-api` server state and 4 virtual minibadge slot selections for 2023 stock mode)
  - `saintcon_2024_stock_nvs`, `saintcon_2024_stock_server` (isolated NVS and fake tower server state for 2024 stock mode)
  - `saintcon_2025_stock_nvs`, `saintcon_2025_stock_se`, `saintcon_2025_stock_server` (isolated NVS, fake ATECC608B slots, and fake game server state for 2025 stock mode)
  - `saintcon_<year>_<mode>_speed` (for cores supporting time scaling)
- **Zero External Dependencies**: No external CDNs, no analytics, and no cookies.

## Core ABI (12-Function Generalized WASM Interface)

Every badge core (`emulator/core/emu.h`) compiles to WebAssembly (`badges/<year>/core.js` + `core.wasm`) with `-sMODULARIZE=1 -sEXPORT_NAME=createCore` and exports these 12 C functions:

```c
void      emu_init(uint32_t seed);                   // boot; reads persisted EEPROM from emu_eeprom()
void      emu_step(uint32_t dt_ms, uint8_t buttons); // advance simulation; button bit meanings come from badge.json
uint16_t* emu_framebuffer(void);                     // emu_fb_width() * emu_fb_height() RGB565, little-endian, row-major
int       emu_fb_width(void);                        // LCD width in pixels (240 for 2021/2025, 320 for 2023/2024, 360 for 2026)
int       emu_fb_height(void);                       // LCD height in pixels (240 for 2021/2023/2024, 320 for 2025, 360 for 2026)
uint8_t*  emu_leds(void);                            // emu_led_count() * 3 bytes RGB in hardware data-chain order
int       emu_led_count(void);                       // RGB LED count (256 for 2018, 1 for 2021, 20 for 2023/2025, 0 for 2024, 9 for 2026)
uint8_t   emu_backlight(void);                       // 0-255 LCD backlight level
uint8_t*  emu_eeprom(void);                          // emu_eeprom_size() bytes persisted by the browser shell
int       emu_eeprom_size(void);                     // EEPROM byte length (512 for 2021/2024/2025, 128 for 2023, 1024 for 2026)
int       emu_eeprom_dirty(void);                    // returns 1 once after each EEPROM write, then 0
void      emu_set_speed(uint32_t mult);              // time multiplier (used by 2025 pet mode; no-op on stock cores)

// Optional extensions exported by touchscreen / IR / accelerometer / minibadge cores (e.g. 2023, 2024):
void      emu_set_touch(int pressed, int x, int y);  // capacitive touch state in [0..fb_width-1] x [0..fb_height-1]
void      emu_send_ir(uint32_t code);                // inject 32-bit NEC IR frame into virtual receiver
void      emu_set_accel(int16_t x, int16_t y, int16_t z); // set raw accelerometer XYZ sample (16384 = +1g at +-2g)
void      emu_set_minibadge(int slot, int catalog_index); // insert virtual I2C minibadge (0..29, or -1 empty) into 2023 slot 0..3
```

For firmwares whose `main()` or FreeRTOS tasks block inside polling, queues, or `vTaskDelay()` / `sleep_ms()` loops (such as the 2024/2025 ESP-IDF + LVGL firmwares and 2026 Pico SDK firmware), the platform layer yields cleanly using Emscripten fibers (`ASYNCIFY` + `emscripten_fiber_*`) in WASM and POSIX `ucontext` in the native `emu-cli` binary.

`emulator/cores/2018/build.sh` runs `fetch-upstream.sh` (staging `Badge/Badge Source Code/` at commit `fee2837d4607` without upstream `Readme.md` files + real `micropython/micropython` `v1.24.1` at `ecfdd5d6f9be` into git-ignored `emulator/cores/2018/upstream/`, scrubbing the `hcid.py` hash salt, conference Wi-Fi password, `flag()`, `www/` HTML-comment flags, and `configure.py` default SSID, applying the two 1-line flash-parity fixes documented in `emulator/cores/2018/UPSTREAM.md`, and verifying zero original secret values exist anywhere in `upstream/Badge/`, `emulator/web/`, or git-tracked files), compiles MicroPython (`ports/webassembly` + `py/`/`extmod/`/`shared/`) and `emulator/cores/2018/platform/` inside `emscripten/emsdk:3.1.73` (`emulator/web/badges/2018/core.{js,wasm}`) and natively (`emulator/cores/2018/emu-cli`), and generates `emulator/web/badges/2018/THIRD_PARTY_LICENSES.txt`.

Hardware shims in `emulator/cores/2018/platform/` (verified against `Badge/Badge Source Code/`):
- **8×32 LED Matrix (`i2c` bus 1, `SCL=GPIO 26`, `SDA=GPIO 25`, `100 kHz` at `python_files/main.py:31`)**: Two `IS31FL3730` dual-8×8 matrix drivers at `0x60` (left 16 columns `U2`) and `0x61` (right 16 columns `U3`, `python_files/matrix.py:8-9`), capturing register `0x00` (`SSD` shutdown bit 7 and `DM` dual-matrix mode `0x18`, `python_files/IS31FL3730.py:10-12`), `0x0D` (`0x0C` 20 mA current limit, `python_files/IS31FL3730.py:7-9`), `0x19` (`0..128` PWM brightness, initialized to `32` at `python_files/main.py:41,77` and `python_files/IS31FL3730.py:14-20`), `0x01..0x08` (Matrix 1 columns `0..7`) + `0x0E..0x15` (Matrix 2 columns `8..15`, `python_files/IS31FL3730.py:22-43`), `0x0C` (Update Column latch, `python_files/IS31FL3730.py:45-49`), and `displayEnable` (`SDB`) on `GPIO 27` (`python_files/main.py:69-70`), rendered both onto the 256 discrete 0603 LEDs (`D1..D256`) on the padlock shackle and onto the `320×96` zoomed matrix canvas.

  Config: `emulator/deploy/wrangler.jsonc` (no request logs, no workers.dev or preview URLs, 404 page, custom domains).
- Deploy: `cd emulator/deploy && npx -y wrangler@4 deploy`. It uploads only `emulator/web/`; never put build files,
  configs or notes in that folder. Wrangler's login lives in `~/.config/.wrangler/config/default.toml`.
- A new year: add it to `LIVE_YEARS` in index.html and museum.html, add `{ "pattern": "<yy>.sc.pug.technology",
  "custom_domain": true }` to the config, deploy.

## Controls by Year

### 2018 (LED matrix badge, Tactile Switches `SW1` / `SW2` / `SW3`)

| Button | Bit | Hardware | Keyboard | On-Screen |
|---|---|---|---|---|
| **UP** | `bit 0` (`0x01`) | `SW1` (`GPIO 16`, active-low) | `ArrowUp` or `W` | Tap/hold `SW1` on left PCB edge or `▲ UP` on pad |
| **DOWN** | `bit 1` (`0x02`) | `SW2` (`GPIO 17`, active-low) | `ArrowDown` or `S` | Tap/hold `SW2` on left PCB edge or `▼ DOWN` on pad |
| **SELECT** | `bit 4` (`0x10`) | `SW3` (`GPIO 18`, active-low) | `Enter`, `Space`, `E`, or `C` | Tap/hold `SW3` on right PCB edge or `● SELECT` on pad |

### 2021 (Combination lock badge, QTouch Dial Wheel + Shackle/Shim + Back Button `SW3`)

| Input / Button | Bit | Hardware | Keyboard | On-Screen |
|---|---|---|---|---|
| **Dial Wheel Drag** | — | 3-channel QTouch wheel (`scroller 0`) | — | Pointer/touch drag around the gold dial ring on the PCB (`#touch-wheel-overlay`) or on the round Big Screen (`#big-screen-canvas`); releasing opens the highlighted `MENU` item |
| **TOP / +** | `bit 0` (`0x01`) | QTouch wheel top (`pos 0`, `270°`) | `ArrowUp` or `W` | `▲ TOP / +` on pad (adds part quantity in `TRADING`; steers toward top in `GAME`) |
| **BTM / -** | `bit 1` (`0x02`) | QTouch wheel bottom (`pos 128`, `90°`) | `ArrowDown` or `S` | `▼ BTM / -` on pad (reduces part quantity in `TRADING`; steers toward bottom in `GAME`) |
| **CCW** | `bit 2` (`0x04`) | Continuous CCW QTouch wheel rotation (`MENU` / `COMBO` / `BUILD` / `GAME`), or left zone (`pos 192`, `180°`) in `TRADING` | `ArrowLeft` or `A` | `◀ CCW` on pad (spins dial CCW — release opens selected `MENU` item; steers CCW in `GAME`; selects previous owned part `<` in `TRADING`) |
| **CW** | `bit 3` (`0x08`) | Continuous CW QTouch wheel rotation (`MENU` / `COMBO` / `BUILD` / `GAME`), or right zone (`pos 64`, `0°`) in `TRADING` | `ArrowRight` or `D` | `▶ CW` on pad (spins dial CW — release opens selected `MENU` item; steers CW in `GAME`; selects next owned part `>` in `TRADING`) |

## Generating `layout.json` and `board.png` from KiCad

`emulator/tools/kicad_layout.py` parses `Saintcon2024.kicad_pcb` + `Saintcon2024Top.kicad_pcb`, `Saintcon2025.kicad_pcb`, and `Apollo.kicad_pcb` (automatically converting KiCad 10 syntax in a temporary build copy when rendering with `kicad/kicad:9.0`), traces WS2812 `DIN`→`DOUT` net chains from the MCU GPIO pin where present, extracts screen/button/IR/outline geometry, renders the 3D raytraced PCB, and writes `emulator/web/badges/<year>/{layout.json,board.png}`:

```bash
python3 emulator/tools/kicad_layout.py --year 2018
python3 emulator/tools/kicad_layout.py --year 2021
python3 emulator/tools/kicad_layout.py --year 2023
python3 emulator/tools/kicad_layout.py --year 2024
python3 emulator/tools/kicad_layout.py --year 2025
python3 emulator/tools/kicad_layout.py --year 2026
# or rebuild all years:
python3 emulator/tools/kicad_layout.py --year all
```

## How to Add Another Badge Year

1. **Vendor Upstream Source & Record Provenance**:
   - Copy the unmodified upstream firmware and `LICENSE` into `emulator/cores/<year>/upstream/`.
   - Document the repository URL, exact commit hash, author handle, and license in `emulator/cores/<year>/UPSTREAM.md`. Keep any unavoidable build patches separate in `emulator/cores/<year>/patches/`.
2. **Extract PCB Layout & Render Board Art**:
   - Extend `emulator/tools/kicad_layout.py` with a `run_<year>()` target that traces the board outline, screen geometry (`rect` or `round`), LED chain order from the MCU data net, and physical switch positions into `emulator/web/badges/<year>/layout.json` and `board.png`.
3. **Implement the Core ABI (`emulator/cores/<year>/`)**:
   - Replace hardware BSP calls (display, LEDs, buttons, EEPROM, clocks, console) with plain C implementing the 12 functions in `emulator/core/emu.h`.
   - Add `emulator/cores/<year>/build.sh` outputting `emulator/web/badges/<year>/core.{js,wasm}` and a native `emu-cli` runner for headless smoke tests.
4. **Create `emulator/web/badges/<year>/badge.json` & Enable in `museum.html`**:
   - Define `year`, `name`, `screen` (`width`, `height`, `shape`), `leds`, `eeprom_bytes`, `buttons` (`bit`, `name`, `keys`, `x_px`, `y_px`), `modes`, `features`, and `credits`.
   - Follow the **Credits rule**: visibly credit the badge creator(s) directly under the badge with links to their profile, source repository, and license, using only names/handles explicitly written in the upstream repo/files (never guess real names).
   - Flip the year's card in `emulator/web/museum.html` from `Coming Soon` to `Live` linking `./?year=<year>`.
