Enigma, Plugboard & Challenge

At-Home Challenge: open the upstream Code Sheet.pdf and Saintcon2019BadgeChallenge.pdf (plus Badge Instructions.pdf). From DIRECTIONS:, press S then K to open ENIGMA EMULATOR, which walks through 5 setup screens (K advances each step): Machine (A=3 / D=4 Rotor), Set Rotors (A/D picks slot, W/S sets 1–9 or BETA/GAMMA), Set Rings (A/D picks slot, W/S sets A–Z for 01–26), Start Pos. (A/D picks slot, W/S sets A–Z), and Plugboard (wire jumper pairs below, then press K to start encoding). Type the ciphertext on A–Z to decode.

Scene Exit / Save: in Enigma Emulator (and Rotor Settings), hold any key 3 seconds to go back. In Games (Snake), steer with WASD and press K to exit. In Challenge Info, envelopes unlock at levels 1, 5, 9, and 13: from EXIT, press W to jump to the newest unlocked envelope, use A/D to move left/right between unlocked envelopes, press K to scroll the selected envelope's message, or press S then K on EXIT. In Custom Message, use W/S (char), A/D (cursor), O (backspace), and K to save & exit. In Minibadge Control and Exit Menu (Animations), use W/S to cycle and K to return to Menu.

Enigma Note: in 3-rotor mode with rotors I–VIII this matches a real three-rotor Enigma, except that the firmware's middle rotor can step twice if you start on both notches (e.g. rotors I II III at AEV → BGW instead of BFW). Its 4-rotor mode (thick reflector B + Beta/Gamma) and rotor IX are its own, not a real M4 or real rotors.

Front vs. back LED positions (KiCad Saintcon2020MainBoard.kicad_pcb): Front (F.Cu): D1 (PA0, top-right), D2 (PA1, bottom-right), D3 (PA2, bottom-left), D4 (PA3, top-left). Back (B.Cu, mirrored as seen when turning the board over): D5 (PA4, top-left), D6 (PA5, bottom-left), D7 (PA6, bottom-right), D8 (PA7, top-right). No file in the repository specifies an LED colour (every schematic/PCB value is LED), so they are drawn in neutral warm white.

How bytes map to LEDs: one letter is one byte (D1..D8 above are ordered MSB b7 to LSB b0). In main.cpp:499-506, every non-zero byte in messages[8][19] has its top bit (0x80) set, and the loop at main.cpp:526-532 (for (int x = 0; x < NUMLEDS - 1; x++)) writes bits 0..6 onto LEDS[7 - x] (D8..D2), leaving LEDS[0] (D1) at 0 (0x00 marks the end of a message).

Test Pads TP1 (PB0) & TP2 (PB1) TP1 pull-up=OFF (0 pulses since reset) • TP2=LOW

Because //DDRB |= 1<<TP1PIN; is commented out at main.cpp:89, TP1 (PB0) stays an input; the PORTB |= 1<<TP1PIN; and PORTB &= ~(1<<TP1PIN); code at main.cpp:385-401, 540-556 only toggles the internal pull-up resistor on input TP1 (1..8 times for modes 0..7 before pausing). TP2 (PB1) is configured as output low at boot (main.cpp:87) and is never pulsed. LONGPRESSTIME and set_sleep_mode(SLEEP_MODE_PWR_DOWN) are configured at boot (main.cpp:29, 77-79), but the firmware never calls sleep_mode() or sleep_cpu().

KiCad Boards & Minibadge Holders

The upstream README.md states that the badge holds 17 minibadges (+V and GND power only — no communication lines). In Hardware/, MinibadgeHoldersPanel.kicad_pcb has 13 MinibadgeHolder plus 4 MinibadgeHolder90 boards; Saintcon2020MainBoard.kicad_pcb has 7 slots, Saintcon2020VerticalBoard.kicad_pcb has 6 slots, and Saintcon2020HorizontalBoard.kicad_pcb has 4 connectors.
